## Full restyle: warm cinema → modern brutalist (both pages)

User asked to change the vibe of the site; chose **both pages** + **modern brutalist**
direction (via AskUserQuestion).

**New visual language** (both `index.html` and `personal/index.html`, content/wording unchanged):
- Concrete paper `#efede7` + hard black `#0b0b0b` + electric blue `#1b1bff` + acid `#d9ff00`.
